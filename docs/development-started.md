This repository now contains the first runnable BINDERY BOX alpha slice:

- Mission Control Web on `http://localhost:4310`
- Manufacturing demo seed data

## Verify

```bash
npm run check

npm run dev:web
```

Open `http://localhost:4310` and run demo tasks from Mission Control.
